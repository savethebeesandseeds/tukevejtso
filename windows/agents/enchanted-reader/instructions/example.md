# Read the screen

Look at the attached screenshot and answer the question or task that is visible.

- Quote the relevant text when it is readable.
- If several questions are visible, answer the one that looks current or selected.
- Say when the image is cut off, blurry, or missing the information you would need.
- Do not invent names, numbers, or instructions that are not on screen.

Replace this file, or add another private `.md` file in this folder. Private instruction files are ignored by Git.
