# Example reference context

This file demonstrates the kind of background document Enchanted Transcription can attach to Agent Insights requests. Create another `.md`, `.txt`, `.json`, or `.csv` file in this folder for your real context; those private files are ignored by Git.

## Sample project

- Project name: Aurora Notes
- Purpose: turn meeting discussions into concise decisions and action items
- Primary audience: a small product and engineering team
- Preferred tone: direct, practical, and clear

## Sample facts

- Weekly planning happens on Monday.
- Decisions should name an owner when the transcript provides one.
- Unknown dates, owners, or commitments should be called out as uncertain rather than invented.

## Response preferences

- Put the most actionable conclusion first.
- Use short paragraphs or compact bullets.
- Distinguish facts in this document from tentative statements heard in the transcript.
